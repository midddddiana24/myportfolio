# Assets Folder Structure

## /public/assets/certs/
Place your certificate images here (PNG, JPG, or WebP).
Then update `src/data/certifications.ts` with the correct paths.

Example:
- `cert-freecodecamp-js.png`
- `cert-google-ux.jpg`

## /public/assets/projects/
Place your project screenshots here.
Then update `src/data/projects.ts` with `image: '/assets/projects/filename.png'`

## /public/assets/icons/
Place any custom icons or logos here (e.g., university logo).
